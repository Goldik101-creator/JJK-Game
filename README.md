A personal JJK Fighting inspired game project.

Runs on Python, and in the terminal.
Has multiple characters, each one with a special ability.
Domain Expansions, Reverse Cursed Technique, Simple Domains, freeze, stun, dodge, brun and etc...

Critical hits, and 7:3 ratio hits are also included.
Yuta's copied techniques are included.

To run, get the files into VS code, and go to main and press start.
There the game will explain itself.
Thank you! and enjoy
